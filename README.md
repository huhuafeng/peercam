# PeerCam

**局域网 / Wi-Fi 点对点摄像头互看** —— 两台手机连接同一 Wi-Fi（或一台开热点），打开 App 即可互相看到对方的摄像头画面，**全程不消耗任何流量**（纯局域网 UDP）。

## 功能

- 🔍 **自动发现**：同一局域网内打开 App，自动发现对方并提示连接（UDP 广播）
- 📹 **双向互看**：双方同时采集并发送 H.264 视频，全双工
- 🔄 **前后摄像头切换**
- 📶 **零流量**：UDP 点对点，纯局域网传输，不经过蜂窝网络
- 🖥️ **低延迟**：默认 640×480@15fps / 1.2Mbps（可调），局域网典型延迟 < 200ms

## 技术栈

| 层 | 技术 |
|---|---|
| 视频编码 | MediaCodec H.264（硬件编码器，Surface 输入） |
| 视频解码 | MediaCodec H.264 + Surface 输出（TextureView） |
| 采集 | Camera2 API + 预览流 |
| 传输 | UDP 自定义协议（28 字节包头 + 1200B 分片） |
| 发现 | UDP 广播（端口 54322）+ 手动 IP 直连 |
| 视频通道 | UDP 54321（收发同一端口） |
| 代码 | Kotlin + Coroutines + ViewBinding |

## 快速开始

### 方式一：下载 APK

1. 打开 [GitHub Releases](https://github.com/huhuafeng/peercam/releases) 页（tag v1.0.0 及以上）
2. 下载 `app-debug.apk`（**已签名，可直接安装**）
3. 安装（需允许"安装未知来源应用"）

### 方式二：自行构建

```bash
./gradlew assembleDebug
# 产物: app/build/outputs/apk/debug/app-debug.apk
```

### 使用步骤

1. 两台手机连接 **同一个 Wi-Fi**（或一台开热点，另一台连接热点）
2. 分别打开 PeerCam（授权相机权限）
3. 稍等几秒，一方会自动发现对方并连接（或手动输入对方 IP）
4. 上下两块画面：上方为对方画面，下方为本机相机预览
5. 点击"切换画面"切换前后摄像头；"停止"断开连接

## 网络协议

- **发现**：UDP 广播 `PCAM|1|<设备名>|<状态>` @ 54322，每 3s 一次
- **视频**：UDP @ 54321，28 字节包头 + 最多 1200B 载荷/分片

| 字段 | 偏移 | 大小 | 说明 |
|---|---|---|---|
| Magic | 0 | 4 | 0x5043414D ("PCAM") |
| Type | 4 | 1 | 1=STREAM 2=PING 3=PONG 4=BYE 5=CONN |
| Reserved | 5 | 1 | - |
| FrameId | 6 | 4 | 帧序号 |
| FragIndex | 10 | 2 | 分片序号 |
| FragCount | 12 | 2 | 总片数 |
| Flags | 14 | 2 | START=1 END=2 KEY=4 CONFIG=8 |
| Timestamp | 16 | 8 | 毫秒时间戳 |
| PayloadLen | 24 | 4 | 载荷长度 |

## 已知限制

- 相机在 App 前台/熄屏时由系统管理（Android 后台相机限制）
- 苹果 iOS 版本不在本仓库支持范围（需另用 iOS 原生方案）
- 部分公共 Wi-Fi（AP 隔离）无法发现对方，建议用热点方案
- Release 附带的 `app-debug.apk` 为 debug 签名（可安装）；`app-release-unsigned.apk` 仅作存档（需自行签名）
